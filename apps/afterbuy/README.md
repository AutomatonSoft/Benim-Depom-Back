# Продажи eBay Depotum через Afterbuy JV

Используется существующее подключение `AFTERBUY_JV_*`: новых аккаунтов и токенов нет.
`PaymentInfo.PaymentMethod = eBay Managed Payment` (без учёта регистра/пробелов)
или `ItemPlatformName = eBay / ebay.de` определяет канал `ebay`.
В БД `account=jv` означает подключение Afterbuy, а не продавца eBay JV.

Для eBay `SoldItem.Anr` сравнивается строго с `EbayOfferPreparation.listing_id`
и `listing_id_history`, только для production/Depotum. `ItemID` остаётся ключом
строки продажи Afterbuy. Подстановка по EAN/SKU для eBay запрещена.
Неизвестный или неоднозначный listing ID не создаёт товарную позицию, статистику
или уведомление. Заголовок заказа может сохраниться без позиций.
Товары с архивным статусом не сопоставляются, как и на остальных площадках.

Повторный импорт обновляет существующую позицию по ключу Afterbuy; снимок цены
карточки и уведомления используют прежние механизмы. Статистика добавляет
канал `(ebay, jv)` — продажи Depotum через Afterbuy JV.
Операции синхронизации остатков eBay этим изменением не добавлены.

## Деплой и проверка

Перед запуском обновлённых web/worker применить `python manage.py migrate`.
Миграции: `ebay.0008_listing_id_history`, `afterbuy.0006_ebay_marketplace`.
Миграция сохраняет текущие известные listing ID; дальнейшие публикации сохраняют
прежний и новый ID вместе с состоянием подготовки. Перезаписанные до миграции
ID автоматически не восстанавливаются: их нужно сверить и добавить отдельно.

Синхронизация использует существующее окно `AFTERBUY_LOOKBACK_HOURS` (по умолчанию
12 часов). Для более старых продаж нужен отдельный запуск с нужным диапазоном,
самостоятельно бесконечную историю импорт не запрашивает.

После деплоя сверить обезличенный XML реальной продажи: `PaymentMethod`, `Anr`,
`ItemID`, `ItemPlatformName`. Скриншот интерфейса сам по себе не подтверждает,
какое XML-поле содержит номер eBay в конкретном подключении.
Проверить известный listing ID, сторонний listing ID с совпадающим SKU и повторный
импорт того же заказа. Новые проверки в `tests/unit/test_afterbuy_ebay.py` используют
моки/тестовую БД, обращения к реальному Afterbuy при разработке не выполнялись.
